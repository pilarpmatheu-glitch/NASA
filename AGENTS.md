# Criterio de color acordado para EmberSpot

Aplicar esta escala fija a los valores diarios mostrados en los calendarios, incluida la mediana histórica cuando haya un valor calculable:

- Verde / baja: 1–17 detecciones.
- Amarillo / media: 18–34 detecciones.
- Naranja / alta: 35–77 detecciones.
- Rojo / muy alta: 78 o más detecciones.

Un valor ausente o sin detecciones verificables se muestra gris. No convertir ausencia de datos en cero. Las medianas históricas pueden tener decimales de 0,5: redondear al entero más cercano sólo para elegir color, manteniendo el valor original visible. Mantener los umbrales y la leyenda sincronizados; no volver a calcularlos como percentiles ni reemplazarlos por otra escala sin una indicación del equipo. Este criterio reemplaza la escala anterior de 1, 2 y 4,5.
